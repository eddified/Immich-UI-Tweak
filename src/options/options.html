Immich URLs

The extension runs only on pages whose URL starts with one of these entries (max 32).

    When Show Profile Icon Overlays is on, partner avatars appear on thumbnails and in the photo viewer. Your own assets show an overlay only if Show Own Profile Icon is also checked.

    By default, Immich opens the command palette when you press /. When this option is on, / moves focus to the main search field in the top bar so you can type in the search field. On narrow layouts where that field is replaced by a search icon, / effectively taps that icon.

    When enabled, a link with the photo coordinates appears above the map in the info panel and opens Google Maps in a new tab.

    When enabled, Immich's built-in map (OpenStreetMap tiles) is hidden in the info panel and a Google Maps embed is shown for the same coordinates. Loads content from Google when the map is visible.

    This will show file location even for partner photos!

    Privacy Policy

    This extension does not collect any data. Zip. Zero. Nada. Your pictures are safe. This extension does not make any modifications to any of your Immich photos, videos, metadata or settings. Its effects are entirely limited to improving the Web UI.
